# Plans and decisions

- **`docs/plans/`**: active plans only, for work that's planned or in
  progress. Keep them current as decisions change.
- **`docs/decisions/`**: one short, permanent record per shipped feature: what
  was decided and why. Start from [0000-template.md](../decisions/0000-template.md).

**When a plan ships:** write its decision record
(`docs/decisions/NNNN-name.md`) and **delete the plan**. Git history keeps the
long version. A shipped plan left in place goes stale and misleads both people
and agents.
